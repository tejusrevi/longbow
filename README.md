# Longbow

Turn-based archery duel for iPhone. The build brief is [LongBow_SPEC.md](LongBow_SPEC.md), and the visual reference is in `Longbow — Game Mockups-png/`.

## Layout

| Folder | What |
| --- | --- |
| `Core/` | Swift package `LongbowCore`: deterministic physics, terrain, rules, AI, seeded RNG. No UIKit, SpriteKit or networking. |
| `Shared/` | `trig_tables.json` and `golden_shots.json`, which the client and (later) the server tests both read. |
| `Game/` | SpriteKit: match scene, camera, archer rig, ink art, halftone shader, `MatchController`. |
| `UI/` | SwiftUI screens and components. |
| `Services/` | Protocols plus v1 implementations (config, audio, haptics, analytics, settings, monetization no-op). |
| `LongbowApp/` | App entry, routing, dependency container. |
| `Resources/` | `DefaultConfig.json`, generated sounds, asset catalog, fonts. |
| `Tools/` | Generators for the trig tables, sounds and app icon. |

`Longbow.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. Don't edit the project file by hand.

## Common commands

```bash
xcodegen generate
```

```bash
swift test -c release --package-path Core
```

```bash
xcodebuild -project Longbow.xcodeproj -scheme Longbow -destination 'platform=iOS Simulator,name=iPhone 17' build
```

Debug launch arguments: `-autoplay` (AI plays both sides, back-to-back matches) and `-oneHitKills` (every hit kills, for fast round and match testing).

## Regenerating data

Only regenerate when the physics contract changes on purpose. The server port must match afterwards.

```bash
python3 Tools/gen_trig_tables.py
```

```bash
swift run -c release --package-path Core golden-gen Shared/golden_shots.json
```

```bash
python3 Tools/gen_sounds.py
```

## Fonts

Drop the Google Fonts listed in `Resources/Fonts/README.md` into `Resources/Fonts/` and re-run `xcodegen generate`. Until then the app uses system fallbacks.

## Music

Add the menu loop as `Resources/Sounds/menu_music.m4a` (`.mp3`, `.wav` or `.caf` also work). `AudioService` picks it up automatically.
